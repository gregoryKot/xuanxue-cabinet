# 0033. Экзамен для учителя — список вопросов, а не блоки

Дата: 2026-09-15. Статус: принято.

## Контекст

Конструктор экзамена показывал учителю блоки: заголовок блока, галочку «Блок
обязателен» и перемешивание вопросов внутри блока. Владелец сказал прямо: слово
«блок» непонятно, нужны перемешивание и порядок ответов. Разбор подтвердил: блок
— устройство хранилища (`exams.blocks`, снимок попытки), вынесенное на экран;
галочка «обязателен» ни на что не влияла — её никто не читал ни при сдаче, ни при
проверке. Заодно вопрос банка создавался черновиком, и владелец не нашёл свои
вопросы в конструкторе: шаг «опубликовать» стоял между «завёл вопрос» и «собрал
экзамен» без причины.

## Решение

Для учителя экзамен — один список вопросов. Перемешивание вопросов остаётся у
единственного блока (`ExamBlockDto.shuffle`), перемешивание вариантов ответа —
новый флаг `shuffleOptions` у самой формы: вариантами экзамен распоряжается
одинаково везде. Оба применяются один раз, при старте попытки, в снимок
(`exam-attempt-snapshot.ts`); проверка идёт по `option.id`, порядку она
безразлична. `required` убран из контракта (shared, DTO, мапперы) и остаётся
необязательным полем записи — старые документы его хранят. Вопрос банка
создаётся `published`; `draft` — осознанный выбор «спрятать», он приезжает явным
полем при создании или кнопкой статуса. Старые многоблочные экзамены сливаются в
один список лениво, при следующем сохранении формы.

## Альтернативы

- Плоский `itemIds` прямо на экзамене: переписывает снимки попыток, проверку и
  бота, expand → contract в один PR не уложить.
- Миграция слияния блоков: `blocks` зашифрован целиком (`encJson`) — пришлось бы
  расшифровывать в миграции ради нескольких тестовых записей.
- Оставить «обязателен» и дописать поведение: правило, которого никто не просил.

## Последствия

Контракт и данные меняются этим PR, экран учителя — следующим; после него слово
«блок» не остаётся ни в одном тексте пользователю. `ExamBlockDto.title`
живёт в контракте только ради старых данных. Вкладка со старым бандлом,
приславшая `required`, получит 400: пайп стоит с `forbidNonWhitelisted`, и
тихого сохранения мимо смысла не будет — перезагрузка страницы лечит. Новая форма шлёт один блок без
заголовка, и `blocksMax`/`itemsPerBlockMax` из `EXAM_LIMITS` фактически
ограничивают один список. Гейты: `tsc` на общем контракте `shared`, юнит-тест
снимка с инъекцией `random` (перестановка вариантов и неизменность автопроверки),
e2e на `shuffleOptions` в ответах `/exams`, spec миграции
`0006-exam-items-published-by-default` на `mongodb-memory-server`.
