# 0008. Канала Threads нет

Дата: 2026-09-05. Статус: принято.

## Контекст

В первом варианте плана среди каналов рассылки был Threads: официальная публикация от
аккаунта учителя, потому что группы Facebook закрыты для API. Threads API требует
одобрения приложения в Meta, заявку нужно было подавать на этапе 0, а до одобрения
работать в полуручном режиме.

## Решение

Владелец проекта решил: Threads школе не нужен. Типы каналов — `telegram`, `vk`,
`manual` (Facebook) и `webpush` (ADR-0006). Заявка в Meta не подаётся, адаптер не
пишется, упоминания из плана, правил и модели угроз убраны.

## Альтернативы

- Threads API — лишний внешний сервис с одобрением приложения ради канала, который
  школе не нужен.
- Оставить в плане «на потом» — мёртвый пункт, который каждый новый агент пытается
  реализовать.

## Последствия

- Union типа канала в `shared/` не содержит `threads`; новый тип канала — отдельное
  решение с ADR.
- Публикация в Facebook остаётся полуручной: текст с кнопкой «скопировать» (ADR-0004).
