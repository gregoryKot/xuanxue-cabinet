# 0071. Баррель `shared` не считается храповиком размера, а взамен обязан быть пустым

Дата: 2026-09-20. Статус: принято.

## Контекст

`shared/src/index.ts` — единственный разрешённый в проекте баррель (CLAUDE.md,
«Дубли и мёртвый код»). Он состоит из строк `export … from` и вырос до 367 строк,
прибавляя по 5–8 строк от каждого нового модуля в `shared`. Выше мягкого потолка
храповика размера (150 строк) файл может только уменьшаться, поэтому такой PR
обязан звать `check-file-size-ratchet.mjs --update`, а `--update` переписывает
`scripts/file-size-baseline.json` целиком.

Отсюда два разных конфликта между параллельными сессиями. Гарантированный: оба PR
правят одну и ту же строку `"shared/src/index.ts": 367` на разные значения — git
такое не сливает никогда. Вероятностный: бейслайн сортировался по размеру по
убыванию, поэтому файл, выросший со 100 строк до 103, переезжал внутри бейслайна,
а размеры плотные (из 1030 записей ~960 меньше 150 строк), и ходы разных PR
перекрывались даже когда сами PR трогали разные файлы. 2026-09-20 так столкнулись
PR #265 и соседние — разошлись перегенерацией.

## Решение

Баррель исключён из храповика размера — рядом с конфигами и по той же причине:
его длина говорит о числе модулей в `shared`, а не о сложности кода.

Исключение не становится местом, где прячут код: `check-shared-exports.mjs`
теперь требует, чтобы в барабане не было ничего, кроме комментариев и
`export … from`. Правило существовало и раньше, но только на словах — `SCHOOL_TZ`
и `WEEKDAY_LABELS_RU` жили прямо в барабане, и оба были невидимы гейту мёртвых
экспортов (он разбирает лишь `export … from`) и исключены из покрытия
(`shared/vitest.config.ts`). Константы переехали в `domain.ts`, утверждение стало
проверяемым. `export *` запрещён там же и по той же причине: через звёздочку гейт
не видит имён.

Заодно бейслайн сортируется по пути, а не по размеру: у записи стабильное место,
и `--update` в двух PR правит разные строки.

## Альтернативы

- Подбарабаны по доменам — CLAUDE.md барабаны запрещает, `check-shared-exports.mjs`
  завязан на один файл, а каждый подбарабан дорастёт до тех же 150 строк.
- Прямые импорты `@xuanxue/shared/lessons` — карта `exports` в `package.json`,
  CommonJS по ADR-0016 и правка 877 файлов-импортёров ради конфликтов в бейслайне.
- Отдельный потолок для барреля — тот же разговор через год, на новом числе.
- `--update <путь>` вместо целого бейслайна — лишний обряд в каждом PR, и
  гарантированный конфликт на строке барреля от него не исчезает.

## Последствия

PR, добавляющий модуль в `shared`, больше не трогает бейслайн размера. Логика в
барабане запрещена не правилом, а гейтом: новая константа живёт в модуле по
смыслу и реэкспортируется. Цена — разовая перегенерация бейслайна целиком (смена
порядка), которая конфликтует со всеми PR, висящими в этот момент.

Гейты: `scripts/check-shared-exports.mjs` (+ `scripts/check-shared-exports.test.mjs`),
`scripts/check-file-size-ratchet.mjs`.
