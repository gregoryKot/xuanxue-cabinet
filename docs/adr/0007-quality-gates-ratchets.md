# 0007. Качество кода держат храповики в CI, а не договорённости

Дата: 2026-09-04. Статус: принято.

## Контекст

Аудит `telegram-bot-2` (2026-07) показал: правила без механизма принуждения не
работают. Лимит 150 строк на файл был записан с первого дня — 76 файлов пробили
потолок 300, худший — 3386 строк. 144 зелёных теста никто не запускал перед деплоем.
Фикс доехал до одного фронтенда из двух. Причина везде одна: правило проверял человек
по памяти.

## Решение

Каждое правило CLAUDE.md имеет гейт — CI, тест, eslint или tsc. Где абсолютный порог
недостижим сразу, стоит **храповик**: счётчик в бейслайне может только уменьшаться,
рост роняет CI, снижение фиксируется `--update`. Новый код всегда рождается под
жёстким порогом (файл ≤300 строк, ноль eslint, ноль дублей).

Набор гейтов на старте: tsc (строгий), eslint с бейслайном 0, prettier, knip, jscpd,
размер файлов, покрытие api и web (vitest `autoUpdate`), робот-фразы, коллизии
маршрутов, сверка `.env.example`, gitleaks, `npm audit`, Docker-смок с health-check,
e2e на владение, jest под второй таймзоной. Локально всё это — `npm run check`.

Мержит агент, открывший PR, после зелёного CI. Владелец PR не мержит.

## Альтернативы

- Ревью «глазами» — не масштабируется на агентов и не переживает усталость.
- Жёсткие пороги сразу — блокируют работу на унаследованном коде; здесь кода нет, но
  храповик всё равно защищает от «временно превысим».
- Pre-commit хуки — замедляют агентов и обходятся `--no-verify`; CI — единственная
  точка, которую нельзя обойти.

## Последствия

- Бейслайны в `scripts/*-baseline.json` — часть кода, меняются осознанно и видны в диффе.
- Правило, получившее гейт, в CLAUDE.md переписывается короче: механизм важнее текста.
- Новый класс проблем → новый храповик в том же PR, что и фикс (как `check-env-example`).
- GitHub: squash-only, заголовок PR = сообщение коммита, ветка удаляется после мержа.
  Branch protection для приватного репозитория требует GitHub Pro (проверено 2026-09-05,
  API вернул 403) — дисциплина мержа держится на правиле 1а CLAUDE.md, а не на GitHub.
- Исключение — объём самого CLAUDE.md: счётчик строк снят 2026-09-20, ADR-0073.
