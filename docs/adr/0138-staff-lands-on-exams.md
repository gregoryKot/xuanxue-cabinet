# 0138. Штат после входа попадает на «Экзамены»

Дата: 2026-09-27. Статус: принято. Дополняет ADR-0025 (навигация по доменам)
и ADR-0046 (у ученика первый экран — «Задания»).

## Контекст

У штата корень «/» вёл на «Занятия» (планирование) с самого начала кабинета —
`STAFF_ROOT_PATH` в `screenAccess.ts`. Владелец 2026-09-27: «сделай экзамены
основным экраном при входе» — учитель большую часть времени в кабинете теперь
работает именно с экзаменами (собирает форму, смотрит очередь проверки), а не
с расписанием. Ученик уже открывает при входе «Задания» (ADR-0046) — то же
решение для штата: первый экран — раздел, с которым чаще всего работают, а не
раздел, который завели первым.

## Решение

- `STAFF_ROOT_PATH` (`screenAccess.ts`, экспортирован) — теперь `/exams`, было
  `/planning`. `rootPathFor(me)` и все её потребители (`AppShell.tsx`,
  `cabinetRoutes.tsx`, `prefetchFirstScreen.ts`) меняются одной строкой.
- `EMPTY_PATH_FALLBACK` (`routeMatch.ts`, опорный путь для «/» без сегментов)
  импортирует `STAFF_ROOT_PATH`, а не держит свой литерал: два литерала уже
  разошлись бы при этой самой правке, а `prefetchFirstScreen.ts` греет данные
  экрана по `matchRoute('/')` для штата ровно потому, что `canSeeRoute(штат,
'/')` истинна на любом пути — молчаливое расхождение прогрело бы данные не
  того экрана.
- `STAFF_NAV_ITEMS` (`navItems.ts`) — «Экзамены» первым пунктом, «Занятия»
  вторым: тот же порядок, что открывается при входе, как у ученика.
- «Занятия» (`PlanningScreen.tsx`) остаются вторым пунктом меню без изменений
  в раскладке — только перестают быть маршрутом корня.

## Альтернативы

- **Свой стартовый экран на человека, настройка в профиле.** Владелец не
  просил выбор для каждого учителя — один экран на всех штата, ещё одна
  настройка ради того, что никто не спрашивал.
- **Оставить «Занятия» корнем, добавить «Экзамены» уведомлением поверх.**
  Не решает задачу: владелец прямо назвал экран, на который штат должен
  попадать первым, не подсказку сверху прежнего.

## Последствия

- Ссылка «Школа Сюань-Сюэ» (знак в колонке/строке) у штата ведёт на
  «Экзамены» — тот же `rootPathFor`, что использует «/».
- Гейты: `screenAccess.test.ts` (`rootPathFor` — штат), `routeModules.test.ts`
  (`matchRoute('/')` — чанк «Экзаменов»), `prefetchFirstScreen.test.ts` и
  `routePrefetch.test.ts` (прогрев «/» — данные «Экзаменов»), `navItems.test.ts`/
  `AppNav.test.tsx`/`AppShell.test.tsx` (порядок пунктов), `App.test.tsx`
  (смоук «/» → «Экзамены»).
