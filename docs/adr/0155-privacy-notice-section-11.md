# 0155. Политика конфиденциальности по статье 11: ответственный — настройка школы, сроки — из констант, подрядчики — под гейтом

Дата: 2026-09-29. Статус: принято. Дополняет [ADR-0145](0145-google-login-and-linking-by-email.md):
страница `/privacy` появилась там, здесь она доведена до того, что требует закон.

## Контекст

Страницу `/privacy` писали под Google: без публичной политики консоль не переводит
OAuth-приложение в режим «In production». Закон о защите частной жизни Израиля
(статья 11 в редакции поправки 13, в силе с 14.08.2025) требует другого: любой запрос
личных данных сопровождается сообщением. В нём сказано, обязан ли человек их давать или
это его воля и что будет при отказе; зачем данные нужны; кто владеет базой и как с ним
связаться; кому и зачем данные передадут; есть ли право посмотреть их (статья 13) и
потребовать исправления (статья 14). На просьбу посмотреть данные отвечают за **30
дней**.

На странице не хватало: добровольности и последствия отказа, имени ответственного и
контакта, прав и срока ответа, части подрядчиков (PostHog — ADR-0143, Google, службы
push, GitHub с копиями базы — ADR-0017), места хранения (вне Израиля) и части сроков
(снимок без подтверждения — 90 дней, видео-ответы, журнал сбоев, лента, копии). Ссылка
вела только с экрана входа, а имя у человека просят раньше: на странице приглашения и в
первом сообщении бота.

**Почему это смогло случиться:** текст и его числа были написаны руками под одну цель, а
ничто не сверяло его с системой. PostHog приехал в ADR-0143 без правки страницы, срок
хранения жил в трёх местах (константа, уборщик, текст) без связи между ними. Тот же
класс ошибки нашёл ADR-0152: GitHub с копиями базы был необъявленным обработчиком, а
увидели это глазами, не гейтом.

## Решение

**Ответственный за данные — настройка школы.** Поля `dataControllerName` и
`dataControllerContact` в `settings`, необязательные, без дефолтов, правятся на экране
«Шаблоны» (раздел «Кто отвечает за данные») и отдаются публично через
`GET /auth/config` тем же приёмом, что `schoolSiteUrl`. Пока поля пусты, страница пишет
«спросите учителя школы», а не выдумывает имя. Это публичный текст — `plain` в
`SETTINGS_FIELD_POLICY` с причиной. Отдельного эндпоинта нет: `/auth/config` уже
публичный и читается экраном входа. Реализовано в предыдущем PR этой пары.

**Сроки хранения в тексте — из констант.** Число не пишется руками: текст собирается из
констант, по которым данные удаляются (`PAYMENT_SCREENSHOT_TTL_*`,
`ANSWER_VIDEO_RETENTION`, `APP_ERROR_LIMITS.retentionDays`, `NOTIFICATION_RETENTION_DAYS`,
`BACKUP_RETENTION_DAYS`, `PRIVACY_ACCESS_REPLY_DAYS`). Срок ленты переехал из схемы api
в `shared/`, чтобы его видел и текст. Гейт — `privacyPolicyText.test.ts`: подменяет
константы и проверяет, что новое число дошло до текста.

**Подрядчики — список `PRIVACY_RECIPIENTS` в `shared/src/privacy.ts`** (имя и «зачем»
для человека) под гейтом `api/src/security/privacy-recipients.spec.ts`. Каждая переменная
из `.env.example` и каждый внешний источник CSP обязаны получить решение: подрядчик из
списка или причина, почему данные людей через них не идут. Копии базы проверяются по
`backup.yml`: запасной путь в артефакт GitHub есть — GitHub в списке, `retention-days`
совпадает с `BACKUP_RETENTION_DAYS`, путь в R2 есть — Cloudflare в списке. Новая служба
без строки в списке — красный тест.

**Ссылка там, где просят данные.** `PRIVACY_PATH` в `shared/` — одна на экран входа,
страницу приглашения `/join/:code` (компонент `PrivacyLink`) и первое сообщение бота
после присоединения по ссылке (адрес строится от `PUBLIC_URL`).

## Альтернативы

- Имя и контакт в env или константе — нарушает «всё настраивается в интерфейсе»: сменился
  ответственный, и нужен разработчик. Имя владельца в коде — персональные данные в
  репозитории и ложь после смены.
- Текст страницы в БД, правится на экране — юридический текст меняется вместе с набором
  данных, то есть с кодом и в PR; в БД лежит только то, что школа знает лучше нас.
- Список подрядчиков выводить из env и CSP автоматически — «зачем» для человека машина не
  выведет; оставили ручную запись под сверкой.
- Отдельный публичный маршрут под два поля — маршрут, DTO и e2e ради того, что уже отдаёт
  `/auth/config`.

## Последствия

- Владельцу один раз заполнить два поля на «Шаблонах» (RUNBOOK, «Что ещё настроить»).
- Новая служба, срок хранения или коллекция с персональными данными — правка текста
  страницы и/или `PRIVACY_RECIPIENTS` в том же PR; забыть о службе тест не даёт.
- Когда последующий PR ADR-0152 уберёт запасной путь в артефакт, `privacy-recipients.spec.ts`
  покраснеет — вместе с ним из списка уходит GitHub и из текста «пока копии не переехали».
- `PATCH /settings` доступен teacher/assistant/admin — публичный текст может поправить и
  помощник; так же устроен `schoolSiteUrl`.
- Открытое, не решаемое кодом: где физически стоят Railway, Atlas и R2 для файлов (текст
  говорит «ЕС и США»), договоры с подрядчиками (SECURITY §5, ADR-0152), регистрация базы и
  срок хранения ответов на экзамены — вопросы владельцу и юристу, текст страницы их не
  заменяет.
