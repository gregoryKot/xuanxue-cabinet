# 0170. Публичное расписание `GET /api/public/lessons` для daychi — без Zoom, два режима выборки

Дата: 2026-10-05. Статус: принято.

## Контекст

Daychi — нативное приложение школы — читает расписание кабинета. Контракт Workshop ([public-lessons.md](https://github.com/dveyarangi/xuanxue-workshop/blob/4aec5f84130c2dd8df6875c30fd94c3cf2a5ec74/docs/contracts/public-lessons.md), ревизия 4aec5f8) требует чтение без credential, поля без Zoom, два режима выборки и лучшее доступное расписание: битая запись выпадает из ответа с error-логом, остальные отдаются. Решение владельца 2026-10-04: расписание без Zoom публично, с Zoom — только по сессии (`/me/lessons`). Workshop issue #5.

## Решение

Отдельный маршрут `GET /api/public/lessons` (`@Public()`, ответ — голый массив `PublicLessonDto[]` из `shared/`), свой сервис и явная проекция-allowlist `projectPublicLesson`. Режимы: «ближайшие» (`startsAt >= now`, `limit` 1–50, по умолчанию 10) либо «окно» (оба `from`/`to` со смещением, `from <= startsAt < to`, не шире 28 суток UTC, без лимита); смесь, половина окна и неизвестный параметр — 400 `invalid_input`. Отменённые занятия включены.

Проекция проверяет каждое выбранное занятие и его класс и возвращает DTO либо причину. Занятие с причиной (класс не найден, `durationMin` не конечное число, `startsAt` не дата, `format` или `status` вне перечисления, обязательная строка не строка, id не ObjectId, `tags` не массив строк, `location` есть и не строка) выпадает из ответа 200; сервис пишет `error`-лог с причиной, `lessonId`, `classId` и `requestId`, без темы и Zoom. Лог стоит в сервисе: ответ успешный, глобальный фильтр 500 его не увидит. Битый общий класс выкидывает все свои занятия. «Ближайшие» берут `limit` кандидатов до проверки и выпавшее не добирают. Все кандидаты битые и кандидатов нет — оба `[]`, логи пропуска только у первого.

Сбой чтения занятий или классов, ошибка расшифровки класса и ошибка кода не превращаются в пропуск: исключение доходит до глобального фильтра, ответ — 500 `internal_error` без массива.

## Альтернативы

- Флаг на `/me/lessons`, убирающий Zoom: один маршрут с двумя проекциями, новое поле при ошибке утекло бы в публичный режим; плюс маршрут требует сессии.
- Публичный токен или ключ приложения: контракт требует чтение без credential, секрет в нативном клиенте всё равно не секрет.

## Последствия

- Первый публичный маршрут с данными школы. Троттлинг — глобальный, по IP (ADR-0164), `@SkipThrottle` не ставится.
- Утечку Zoom держит e2e: ни ссылки, ни пароля класса и занятия ни без сессии, ни с сессией admin; `public-lesson.mapper.spec.ts` сверяет точный набор ключей.
- Пропуск битых занятий и 500 на сбой чтения держит `public-lessons-omission.e2e-spec.ts`: смесь, общий класс, починка, пустые выборки, «ближайшие» без добора, лог с причиной и id без Zoom.
- `check-ownership-e2e.mjs` закрыт проверкой 404 на лишний путь под `/api/public/lessons`: владельца у общего расписания нет.
- Пределы (10, 50, 28 суток) — контракт Workshop, менять только вместе с ним.
- Пустой ответ не доказывает, что занятий нет: признака полноты в ответе нет по контракту, пропуски видны только в логах.
- Экран ученика проверку не проходит: дату без класса он по-прежнему молча пропускает.
