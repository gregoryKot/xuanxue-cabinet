# 0073. Потолок строк CLAUDE.md снят

Дата: 2026-09-20. Статус: принято. Уточняет ADR-0007 (гейт на каждое правило).
Номер 0073, а не 0072: пока PR готовился, номер 0072 занял ADR про теги занятия (#274).

## Контекст

`scripts/check-claude-md-size.mjs` ронял CI, когда CLAUDE.md перерастал 400 строк.
Гейт появился по аудиту 2026-09-12 (пункт M10): принцип «индекс правил, не
энциклопедия» был записан с первого дня, и файл всё равно дорос до 404 строк.

Счётчик строк меряет объём, а дорожим мы другим: чтобы подробности жили в `docs/`, а
в своде оставались правило и ссылка. Файл упёрся ровно в 400, и теперь каждое новое
правило проходит не через вопрос «оно того стоит», а через поиск, что выкинуть, —
выкидывают же обычно то, что дешевле переписать. Цена ошибки несимметрична:
ненаписанное правило пропадает молча, лишний абзац стоит абзаца.

## Решение

Гейт снят: скрипт удалён, шаг «потолок CLAUDE.md» убран из CI и из `npm run gates`.
Принцип «индекс правил, не энциклопедия: подробности — в `docs/`» остаётся в разделе
«Документация» и держится ревью.

## Альтернативы

- Поднять потолок до 500 — та же стена через квартал, только дальше.
- Считать разделы или ссылки вместо строк — сложнее, меряет ровно то же самое.
- Выносить в `docs/` дальше — так и делали (PWA, SECURITY, RUNBOOK); выносить
  осталось нечего, а в стену упирается каждое новое правило.

## Последствия

- CLAUDE.md растёт без гейта. Разрастание ловит ревьюер вопросом «это правило или
  подробность?» — подробность уезжает в `docs/`.
- ADR-0007 держится для правил о коде: гейт нужен там, где нарушение невидимо.
  Объём самого свода виден в диффе, поэтому здесь хватает глаз.
- Запись нужна, чтобы гейт не вернули «по аудиту M10» не разобравшись: он снят
  осознанно 2026-09-20.
