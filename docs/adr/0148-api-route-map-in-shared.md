# 0148. Карта маршрутов в `shared/` — контракт кабинета и API

Дата: 2026-09-29. Статус: принято. Шаг 1 из docs/PLAN.md §17.1.

## Контекст

`apiFetch<T>(path)` принимает строку, тип ответа ставит рукой автор вызова.
`tsc` расхождение не видит: `api` и `web` друг о друге не знают, e2e
проверяют только API, тесты web мокают `apiFetch`. Цена уже заплачена: #345
чинил шесть маршрутов, где кабинет ждал DTO, а приходил 204 или часть DTO;
2026-09-27 на проде страница материала открывалась с «Cannot GET
/api/materials/:id». Узкий гейт `check-editor-routes.mjs` закрывает только
`GET /:id` у редакторов.

## Решение

`shared/src/api-routes.ts` — карта `'МЕТОД /путь' → { query; body; response }`
на типах из `shared/`, параметры пути (`:id`) выводятся из ключа типом.
Web зовёт `apiRoute(ключ, { params, query, body })` (`web/src/api/apiRoute.ts`,
обёртка над `apiFetch`): путь, метод и типы — из записи, несуществующий ключ,
забытый `:id`, лишнее тело или не тот тип ответа — ошибка `tsc`. Контроллер
ставит `@ApiRoute(ключ)` рядом с `@Get/@Post`: декоратор принимает только
метод, возвращающий `Promise<response>`, DTO тела и query — `implements
ApiRouteBody<ключ>`/`ApiRouteQuery<ключ>`. e2e на настоящем AppModule
(`api/test/api-routes.e2e-spec.ts`) сверяет ключи карты с маршрутами Nest:
ключ без обработчика или `@ApiRoute`, не совпавший с маршрутом, роняют тест.
Образцовый домен — лента уведомлений `/me/inbox` (четыре маршрута, один
контроллер, была в #345). Только типы TypeScript, без зависимостей.

## Альтернативы

- Храповик по тексту `check-api-contract.mjs` — отвергнут в PLAN §17.1:
  слепые пятна (путь из константы, путь из другого файла), лечит симптом.
- Генерация клиента из OpenAPI (`@nestjs/swagger` + генератор) — зависимость
  и шаг сборки ради того, что компилятор делает на общих типах.
- Маршрут задаёт сам `@ApiRoute` вместо `@Get/@Post` — меньше дублирования,
  но гейты `check-route-collisions.mjs` и `check-ownership-e2e.mjs` читают
  декораторы Nest по тексту; сходство ключа с маршрутом проверяет e2e-сверка.

## Последствия

- Новый маршрут, который зовёт кабинет, приезжает записью в карте, вызовом
  `apiRoute` и `@ApiRoute` в контроллере.
- Строковый `apiFetch` живёт, пока есть вызовы; их число держит храповик
  `check-string-api-fetch-ratchet.mjs` — только вниз.
- Путь для таблицы предзагрузки собирает `apiRoutePath` — тот же, что уйдёт
  в сеть, иначе ключ кэша `prefetchCache.ts` разойдётся.
- Перенос остальных доменов — PLAN §17.1, шаг 2; последний PR удаляет
  строковый `apiFetch`, храповик, `check-editor-routes.mjs` и `apiPaths.ts`.
