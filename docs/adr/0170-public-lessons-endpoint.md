# 0170. Публичное расписание `GET /api/public/lessons` для daychi — без Zoom, два режима выборки

Дата: 2026-10-05. Статус: принято.

## Контекст

Daychi — нативное приложение школы — читает расписание кабинета. Контракт Workshop ([public-lessons.md](https://github.com/dveyarangi/xuanxue-workshop/blob/e209d27239391be3af2be71b898c79f453851c01/docs/contracts/public-lessons.md), ревизия e209d27) требует чтение без credential, поля без Zoom, два режима выборки и отказ вместо молчаливо потерянного занятия. Решение владельца 2026-10-04: расписание без Zoom публично, с Zoom — только по сессии (`/me/lessons`). Workshop issue #5.

## Решение

Отдельный маршрут `GET /api/public/lessons` (`@Public()`, ответ — голый массив `PublicLessonDto[]` из `shared/`), свой сервис и явный маппер-allowlist `toPublicLessonDto`. Режимы: «ближайшие» (`startsAt >= now`, `limit` 1–50, по умолчанию 10) либо «окно» (оба `from`/`to` со смещением, `from <= startsAt < to`, не шире 28 суток UTC, без лимита); смесь, половина окна и неизвестный параметр — 400 `invalid_input`. Отменённые занятия включены. Занятие без класса — `Error` и 500 `internal_error` без частичного массива: общий join получил режим `missingClass: 'fail'`, экран ученика остался на `'skip'`.

## Альтернативы

- Флаг на `/me/lessons`, убирающий Zoom: один маршрут с двумя проекциями, новое поле при ошибке утекло бы в публичный режим; плюс маршрут требует сессии.
- Публичный токен или ключ приложения: контракт требует чтение без credential, секрет в нативном клиенте всё равно не секрет.
- Молчаливый пропуск занятия без класса, как на экране ученика: daychi показал бы «занятия нет» вместо ошибки обновления.

## Последствия

- Первый публичный маршрут с данными школы. Троттлинг — глобальный, по IP (ADR-0164), `@SkipThrottle` не ставится.
- Утечку Zoom держит e2e: ни ссылки, ни пароля класса и занятия ни без сессии, ни с сессией admin; `public-lesson.mapper.spec.ts` сверяет точный набор ключей.
- `check-ownership-e2e.mjs` закрыт проверкой 404 на лишний путь под `/api/public/lessons`: владельца у общего расписания нет.
- Пределы (10, 50, 28 суток) — контракт Workshop, менять только вместе с ним.
