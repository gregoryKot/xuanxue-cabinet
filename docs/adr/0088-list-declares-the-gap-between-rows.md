# 0088. Промежуток между строками объявляет список, а не строка

Дата: 2026-09-21. Статус: принято.

## Контекст

Владелец трижды прислал один и тот же снимок: карточки списка стоят вплотную,
швы между ними не читаются, несколько плашек выглядят одной. Первые два раза
(«Вопросы» и «Каналы», потом очередь проверки) чинили по месту — строку лишали
своего фона и сводили список в одну карточку с волосяными линиями
(docs/adr/0043, `oneCardListStyle`). Третий раз пришёл с «Заданий» ученика: там
карточка экзамена по замыслу остаётся отдельной тёплой плашкой, а `<ul>` был
объявлен как `{ margin: 0, padding: 0, listStyle: 'none' }` — без `gap`.

Причина повторов одна: промежуток между строками нигде не был ничьей
обязанностью. `<ul>` по умолчанию обнуляли до «голого списка», строка своего
внешнего отступа не задавала — и пока строка была без фона, этого не было
видно. Как только строке давали поверхность, список слипался, и ловил это
только глаз владельца на снимке. К моменту решения тот же литерал был
переписан в четырнадцати местах: шесть раз с `gap`, восемь раз без.

## Решение

Промежуток задаёт контейнер списка, а не строка, и каждый список объявляет его
явно. Форм ровно три, все три объявлены один раз в
`web/src/components/listCardStyles.ts`:

- `cardListStyle` — колонка со `gap`: строка несёт свою поверхность (фон,
  радиус, тень), между строками нужен воздух;
- `oneCardListStyle` — «список одной карточкой»: общий фон, строки разделяет
  волосяная линия снизу (ADR-0043);
- `dividedListStyle` — голый список с `gap: 0`: строка без своей поверхности,
  ритм держит линия у самой строки. Ноль здесь не отговорка, а заявление.

## Альтернативы

- **Отступ у строки (`marginBottom`)** — лишний отступ под последней строкой и
  два места правды, когда список вложен в другой список.
- **Все списки свести в одну карточку с линиями, как в ADR-0043** — приём хорош
  для плотной строки-ссылки, но «Задания» — крупные плашки с описанием и
  кнопкой; в одной карточке они читаются сплошным текстом.
- **Оставить правилом в CLAUDE.md без гейта** — уже проверено трижды: правило
  без механизма принуждения не работает.

## Последствия

- Свой литерал `{ margin: 0, padding: 0, listStyle: 'none' }` больше не пишется:
  список берёт одну из трёх готовых форм и тем самым называет свой замысел.
- Гейт `scripts/check-card-list-gap.mjs` (в `npm run gates` и в CI) разбирает
  `web/src` и роняет сборку на списке, который не объявил ни `gap`, ни
  `overflow: 'hidden'`. Бейслайна нет: гейт абсолютный, как
  `check-route-collisions.mjs`.
- `gap` из комментария гейт не засчитывает — разбор идёт по коду с затёртыми
  строками и комментариями.
- `ListScreenBody` больше не имеет умолчания для `listStyle`: проп обязателен.
  Умолчание было «голым списком» и ждало первого экрана с карточкой-строкой.
