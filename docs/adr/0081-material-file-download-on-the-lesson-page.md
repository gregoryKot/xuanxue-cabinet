# 0081. Файл материала на странице даты занятия — только скачивание

Дата: 2026-09-21. Статус: принято.

## Контекст

Файл материала (ADR-0057) приехал полем на странице материала:
«Добавить файл» → имя, размер, «Скачать», «Заменить», «Убрать». В секции
«Материалы» страницы даты занятия файла не было видно вовсе — учитель после
занятия открывает именно эту страницу, и о том, что у материала есть
конспект, узнавал только уйдя в раздел «Материалы».

Поле не поставили из-за правила «Одна механика — один компонент». Владелец
школы это отклонил: правило запрещает вторую реализацию одного ввода, а не
второе место, где стоит один и тот же компонент.

Строка списка узкая — название, подпись «вид · теги» и кнопка
«Добавить»/«Убрать», — и проверяется она на 360 px. Полное поле с тремя
действиями в неё не встаёт.

## Решение

В строке материала — только «Скачать файл», и только когда у материала есть
файл и хранилище подключено (`fileStorageEnabled`). Загрузка, замена и
удаление остаются на странице материала. Сама ссылка — общий компонент
`web/src/materials/MaterialFileDownloadLink.tsx`, он же стоит в поле файла и
в карточке библиотеки ученика.

## Альтернативы

- Поле `MaterialFileField` целиком в строку — три действия и подсказка про
  форматы ломают строку на 360 px, а загрузка в двух местах ещё и требует
  двух путей перечитывания списка.
- Ссылка только у привязанных материалов, не у кандидатов «Из библиотеки» —
  строка одна на оба списка, и разъехаться по виду они не имеют права.
- Показывать ссылку по одному `material.file`, без признака хранилища — при
  снятых ключах R2 ссылка ответила бы 503 вместо того, чтобы не появиться.

## Последствия

Признак хранилища секция читает один раз (`useAuthConfig`) и раздаёт обоим
спискам: запрос в строке стоил бы по вызову на материал. Права на файл
по-прежнему проверяет сервер (`isMaterialLocked`), у закрытого материала
`file` в ответе нет вовсе — ссылке неоткуда взяться.

Гейты: `LessonMaterialsSection.test.tsx` — файл есть, файла нет, хранилище
выключено; `MaterialFileField.test.tsx` и `StudentMaterialCard.test.tsx`
держат ту же ссылку на своих экранах.
